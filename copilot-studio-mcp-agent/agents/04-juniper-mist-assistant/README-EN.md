# Juniper Mist Assistant

An experimental Copilot Studio assistant architecture based on a Juniper MCP service.

## Current status

- The MCP architecture was used in the Claude environment.
- The Juniper MCP was not accessible from Copilot Studio during the last test.
- The integration has not been retested yet.

## Public positioning

This agent must be presented as an integration under evaluation, not as an operational Copilot Studio integration. Do not publish endpoint, authentication or access details.

## To retest

- Current Juniper MCP availability for Copilot Studio.
- Access and authentication requirements.
- Teams/Microsoft 365 publication.
- Agent behavior once the connection is established.
