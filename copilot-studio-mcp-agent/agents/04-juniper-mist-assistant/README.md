# Juniper Mist Assistant

Architecture expérimentale d’un assistant Copilot Studio connecté à un service MCP Juniper.

## État actuel

- L’architecture MCP a été utilisée dans l’environnement Claude.
- La connexion au MCP Juniper n’était pas accessible depuis Copilot Studio lors du dernier essai.
- Cette intégration n’a pas encore été retestée.

## Positionnement public

Cet agent doit être présenté comme une intégration en évaluation, et non comme une intégration Copilot Studio opérationnelle. Aucun endpoint, paramètre d’authentification ou détail d’accès ne doit être publié.

## À retester

- disponibilité actuelle du MCP Juniper pour Copilot Studio ;
- conditions d’accès et d’authentification ;
- publication dans Teams/Microsoft 365 ;
- comportement de l’agent une fois la connexion établie.
