# HPE Networking Presales Advisor Knowledge

A knowledge-grounded Copilot Studio assistant for Networking presales teams.

## Purpose

It helps retrieve and synthesize technical information from a curated knowledge base covering architectures, products, capabilities and enablement material.

## Functional architecture

- Selected documentary sources.
- Retrieval-augmented answers grounded in available knowledge.
- Explicit indication when an answer cannot be established.
- Human review for customer-facing recommendations.

## Points of attention

- Maintain source freshness and quality.
- Document configuration warnings.
- Do not publish the real document inventory or internal paths.
