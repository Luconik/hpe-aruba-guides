# HPE Networking Presales Advisor Knowledge

Assistant de knowledge grounding pour les équipes presales Networking.

## Objectif

Aider à retrouver et synthétiser des informations techniques issues d’un corpus documentaire validé : architectures, produits, fonctionnalités et supports d’enablement.

## Architecture fonctionnelle

- Sources documentaires sélectionnées.
- Recherche/RAG pour ancrer les réponses dans la connaissance disponible.
- Signalement explicite lorsqu’une réponse ne peut pas être établie.
- Revue humaine pour toute recommandation destinée à un client.

## Points de vigilance

- Maintenir la fraîcheur et la qualité des sources.
- Documenter les avertissements de configuration.
- Ne pas publier l’inventaire réel des documents ni leurs chemins internes.
