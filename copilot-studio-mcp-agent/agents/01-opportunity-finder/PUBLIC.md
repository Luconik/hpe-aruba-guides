# Opportunity Finder — public draft

> Draft à valider. Exemple anonymisé et conceptuel.

## Use case

A Copilot Studio agent that helps a technical sales team turn two operational sources into a concise, fact-based opportunity view.

## Conceptual flow

1. Retrieve the relevant coverage scope.
2. Query the opportunity system for open records.
3. Apply the validated ownership mapping.
4. Return a short dashboard with explicit data-quality notes.

## Guardrails

- No strategic recommendations by default.
- No invented amounts, dates or account mappings.
- Missing or failed data sources are reported explicitly.
- The public example must use synthetic records only.
