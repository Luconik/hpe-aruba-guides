# HPEN Partner & Customer Reference Guide

A documentary Copilot Studio assistant that helps partners, resellers and technical teams find the right Networking resource.

## Purpose

It routes users to relevant official resources: documentation, support, lifecycle, training, labs, APIs, communities and architecture guides.

## Functional architecture

- Documentary knowledge base.
- Answers focused on finding and recommending resources.
- Links to official resources whenever possible.
- Separation between reusable public content and proprietary documentation.

## Publication principle

The public version should prioritize official accessible links and original or explicitly reusable documents. The reference PDF used during the work remains an information source and is not copied into this public section.
