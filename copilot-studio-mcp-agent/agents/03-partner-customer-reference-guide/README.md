# HPEN Partner & Customer Reference Guide

Assistant documentaire pour orienter les partenaires, intégrateurs, revendeurs et équipes techniques vers la bonne ressource Networking.

## Objectif

Identifier rapidement une ressource officielle ou pertinente : documentation, support, lifecycle, formation, labs, API, communautés et guides d’architecture.

## Architecture fonctionnelle

- Une base de connaissance documentaire.
- Des réponses orientées recherche et recommandation de ressource.
- Des liens vers des ressources officielles lorsque cela est possible.
- Une séparation entre contenu générique réutilisable et documentation propriétaire.

## Principe de publication

La version publique doit privilégier des liens officiels accessibles et des documents originaux ou explicitement réutilisables. Le PDF de référence utilisé pendant le travail reste une source d’information et n’est pas copié dans cette section.
