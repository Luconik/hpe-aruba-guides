# Politique d'anonymisation

## Remplacements obligatoires

| Élément interne | Placeholder public |
|---|---|
| nom de personne | `[AGENT_OWNER]` |
| adresse e-mail | `[OWNER_EMAIL]` |
| organisation/tenant | `[ORGANIZATION]` |
| site SharePoint | `[KNOWLEDGE_SITE]` |
| liste SharePoint | `[COVERAGE_LIST]` |
| connexion CRM | `[CRM_CONNECTION]` |
| nom de client/compte | `[CUSTOMER_ACCOUNT]` |
| opportunité/deal | `[SYNTHETIC_OPPORTUNITY]` |
| nom d'équipement/site réseau | `[NETWORK_DEVICE]` / `[SITE]` |
| identifiant, URL ou champ interne | `[INTERNAL_IDENTIFIER]` |

## À ne pas publier

- prompts complets et règles de scope commercial ;
- données Salesforce, SharePoint ou Aruba Central réelles ;
- noms de clients, comptes, opportunités, équipements ou sites ;
- adresses e-mail et noms de propriétaires ;
- noms de tenant, environnements et connexions ;
- captures de partage indiquant les utilisateurs ou les droits ;
- métriques d'usage internes non validées ;
- documents propriétaires ou non explicitement réutilisables.

## Captures

Les captures présentes dans le dossier sont considérées comme caviardées et utilisables pour la documentation publique. Le nom de l'auteur peut rester visible volontairement pour attribuer le travail. Les contrôles portent encore sur les noms de clients, comptes, opportunités, sites, équipements, tenant, URLs internes, adresses e-mail tierces et données opérationnelles.
