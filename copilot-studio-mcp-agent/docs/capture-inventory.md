## À vérifier avant de figer les fiches

- rattachement exact de chaque capture de configuration aux fiches : documenté ci-dessus ;
- texte lisible des instructions et descriptions ;
- noms visibles dans les panneaux de partage ;
- présence éventuelle de données commerciales ou d'infrastructure dans les conversations Teams ;
- captures éventuelles du Juniper Mist Assistant ; surtout documenter séparément le blocage MCP Copilot Studio et ne pas présenter l’intégration comme opérationnelle tant qu’elle n’a pas été retestée.
