# Checklist avant publication

## Documentation

- [ ] Une fiche interne existe pour chaque agent documenté.
- [ ] Une version `PUBLIC.md` distincte a été créée.
- [ ] Les affirmations publiques sont vérifiables et non spéculatives.
- [ ] Les informations de facturation, d'usage et de tenant ont été retirées ou validées.
- [ ] Les prompts internes ne sont pas copiés intégralement dans la version publique.

## Captures

- [x] Les captures ont été caviardées par l'auteur.
- [x] Le nom de l'auteur est conservé volontairement pour attribuer le travail.
- [ ] Les noms de tenant, clients, comptes, sites et équipements ont été revérifiés.
- [ ] Les panneaux de partage et droits d'accès ont été revérifiés.
- [ ] Les conversations utilisent des données publiables ou synthétiques.
- [ ] Les captures restent lisibles après caviardage.
- [ ] Les droits de réutilisation des logos, documents et visuels ont été vérifiés.

## GitHub

- [ ] `.gitignore` exclut les exports, archives, captures originales et fichiers sensibles.
- [ ] Aucun secret n'est présent dans l'historique Git.
- [ ] Le README précise le caractère démonstratif et anonymisé des exemples.
- [ ] Le repository est privé tant que la revue n'est pas terminée.

## LinkedIn

- [ ] Le post ne révèle pas de données client ou commerciales.
- [ ] Les exemples sont présentés comme génériques ou synthétiques.
- [ ] Les captures proposées ont été validées séparément.
- [ ] Le texte est relu en français et en anglais.
- [ ] La publication reste un draft soumis à validation humaine.
